## 为什么手机不能像电脑那样“本地打开”

- **iPhone**：Safari 根本不允许打开本地 html 文件（`file://` 被禁），从「文件」App 点开只会得到一个不能用的预览。这是系统限制，跟我的代码无关。
- **安卓**：可以打开，但部分机型会把 `file://` 当成“无来源页面”，**禁止网页存数据**，关掉就丢。我加了检测，这种情况页面顶部会弹橙色提醒。
- 另外，网页要“加到主屏幕、全屏、能离线”，浏览器要求一个地址（https 或局域网 http），光有文件是不够的。

**关键一点：托管不等于把数据放云上。** 托管只托管 index.html、css、js 这几个网页文件，你写的目标、待办、日记一个字节都不会上去，仍然只存在那台手机的浏览器里。

## 真正纯本地的三条路

**① 电脑开着的局域网（推荐，现在就在跑）**
双击 [启动手机访问.bat](2026计划本/启动手机访问.bat) → 手机连同一 Wi-Fi 打开 `http://192.168.1.211:8080`。
全程不出家门、断网也能用、不注册。代价：**电脑得开着**；而且局域网地址最好在路由器里给电脑设成固定 IP，否则 IP 一变，手机主屏那个图标就因为地址变了、数据“找不到”了（数据是跟地址绑定的）。

**② 安卓纯离线**：把 [2026计划本-单机版.html](2026计划本/2026计划本-单机版.html) 拷进手机存储，用 Chrome 打开 `file://` 地址。
如果提示不能保存，就在手机上装个「HTTP Server」这类小 App，把文件夹设为根目录、用 `http://localhost:8080` 打开，数据就正常了。**完全不需要电脑和网络。**

**③ iPhone 纯离线**：Safari 没戏，要装 **Documents by Readdle**（免费），把单机版 html 传进去，用它内置的浏览器打开。能跑，但保存是否可靠取决于版本，我不敢保证。
